From Pixels to Verifiable 3D Worlds.

An independent, evidence-led study of sparse-view reconstruction: what geometry is observed, what is predicted, and how additional photographs change the result.

Open evidence viewer Source on GitHub

The research question

How many photographs does it take to reconstruct a navigable scene—and how much better does each additional view make it? The View Budget Challenge will compare deterministic 1, 2, 3, 5, and 8-view inputs while reserving held-out images for evaluation.

Baseline

Depth Anything V2 Small produces relative, inverse-like depth from one image. We unproject it into an RGB point cloud using explicit assumed intrinsics.

Evidence

Confidence, camera poses, masks, and cross-view support are shown only when supplied by a validated model output. Unknown remains unknown.

Next engine

MapAnything Apache-2.0 is an optional adapter. This repository does not claim that GPU inference or a real multi-view scene has run here.

Current status

No public demonstration photograph is bundled until redistribution rights are verified. Load your own local WIPCLD01 output in the viewer; files remain in your browser.
